# ⚔️ НРИ Трекер Инициативы & Энкаунтеров (TTRPG Initiative Tracker)

Универсальный интерактивный трекер инициативы и менеджер боевых встреч для настольных ролевых игр (D&D, Pathfinder, OSR, Cyberpunk, World of Darkness, PbtA и др.). Работает прямо в браузере и готов к публикации на **GitHub Pages**.

---

## 🌟 Основные возможности

### 1. 📜 Заготовка и сохранение энкаунтеров
* Создавайте боевые сцены заранее перед игровой сессией.
* Указывайте название, локацию, сложность, теги и тактические заметки для мастера (ловушки, триггеры, лут).
* Добавляйте группы существ (например, *«Гоблин-лучник» × 4*, *«Огр» × 1*) с автонумерацией.
* **Запуск боя в 1 клик**: мгновенно переносит выбранный энкаунтер и всю партию игроков в активный боевой трекер.
* Возможность вызывать **подкрепления** прямо во время боя (*«Добавить энкаунтер в активный бой»*).

### 2. 🐉 Локальный бестиарий и шаблоны существ
* **Удобная визуальная форма создания существ** (никакого ручного редактирования сырого JSON!).
* Поля: Имя, Принадлежность (Враг, Союзник, Нейтрал, Окружение), Здоровье (HP), Защита / КД, Модификатор инициативы, чипы тегов и заметки/способности.
* Поиск по имени и способностям, фильтрация по типам и тегам, дублирование и редактирование.

### 3. 🛡️ Постоянная партия игроков (Party)
* Сохранение карточек постоянных персонажей игроков (Имя персонажа, Игрок за столом, HP, КД, мод. инициативы, пассивное восприятие, способности, цвет).
* Добавление всей партии в любой бой одной кнопкой.
* Функция *«Долгий отдых»* — быстрое исцеление всей партии.

### 4. ⚔️ Активный трекер боя
* **Гибкая инициатива**: поддержка кубиков **d20**, **d10**, **2d6**, **3d6** или ручного ввода.
* Автобросок инициативы для NPC в 1 клик или для всех участников.
* Сортировка по инициативе с ручной корректировкой порядка (стрелки вверх/вниз).
* **Счётчик раундов** и индикация: *«Ходит сейчас»* (золотая подсветка) и *«Следующий на очереди»*.
* Горячая клавиша: переход к следующему ходу по нажатию **`Space` (Пробел)**.
* **Управление здоровьем (HP)**:
  * Интерактивная полоса HP с цветовой индикацией.
  * Модальное окно быстрого урона и лечения (кнопки половинного урона, крита `x2`, временных HP).
  * Инлайн-кнопки быстрого изменения: `-5`, `-1`, `+5`.
* **Статусы и состояния (Conditions)**:
  * 16 предустановленных классических состояний + добавление любых произвольных эффектов.
  * Таймер раундов (автоматически уменьшается при окончании хода персонажа или раунда).
* Задержание хода (Delay) и отметка поверженных участников.
* Подробный журнал боевых событий (Combat Log).

### 5. 🎲 Встроенные инструменты мастера
* **Дайс-роллер**: быстрые броски d4, d6, d8, d10, d12, d20, d100 и ввод произвольных формул (например, `2d8+3`, `4d6`).
* **Резервное копирование и перенос**: Экспорт всей базы в единый `.json` файл и импорт обратно на любом устройстве. Все данные автоматически сохраняются в `LocalStorage`.

## 🚀 Запуск и Разработка

### Локальный запуск
1. Убедитесь, что установлен [Node.js](https://nodejs.org/) (версии 18+).
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).

### Сборка проекта
```bash
npm run build
```
Скомпилированные статические файлы будут находиться в папке `dist/`.

## 🌐 Публикация на GitHub Pages

В репозитории уже настроен GitHub Actions workflow (`.github/workflows/deploy.yml`).

1. Откройте репозиторий на GitHub: [github.com/Alvetore/IniTracker](https://github.com/Alvetore/IniTracker)
2. Перейдите в **Settings** ➔ **Pages** (в боковом меню).
3. В разделе **Build and deployment**:
   * В выпадающем списке **Source** выберите **GitHub Actions**.
4. После сохранения workflow соберёт и опубликует сайт по адресу:
   **[https://alvetore.github.io/IniTracker/](https://alvetore.github.io/IniTracker/)**
